Microgrid RL — AI-Optimised Energy Management System

Final-year B.Tech project · Campus-scale solar microgrid optimised with Deep Reinforcement Learning (DQN/PPO)

🏗️

System Architecture

  • Solar PV: 700 W peak (Gaussian bell, noon-centred)
  • Battery: 5 kWh LiFePO₄, 95% round-trip efficiency
  • Campus Load: 150–900 W (morning + lunch + evening peaks)
  • Grid: Time-of-use pricing (peak/off-peak)
🧠

RL State Space

pv_normNormalised PV output [0,1]
load_normNormalised load [0,1]
battery_socState-of-charge [0,1]
hour_sinCircular hour encoding
hour_cosCircular hour encoding
price_normNormalised grid price [0,1]
🎮

Action Space

CHARGESolar surplus → battery
DISCHARGEBattery covers load
IDLESolar-first, grid fills gap
GRID_CHARGEPrice arbitrage charging
🏆

Reward Function

R = − grid_cost × price_factor
   + solar_bonus
   − deep_discharge_penalty
   − overcharge_penalty
   − arbitrage_abuse_penalty

Key Novelties

  • Rigorous rule-based comparison baseline
